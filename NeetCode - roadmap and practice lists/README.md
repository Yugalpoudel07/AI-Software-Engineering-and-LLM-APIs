# 🧠 NeetCode — roadmap and practice lists (Weeks 31–65, habit)

### *3 hours a week, about 3 problems, in roadmap order, for 35 weeks (~100 problems)*

[![Time](https://img.shields.io/badge/Habit-3_hrs%2Fweek-blue?style=flat-square)](#-the-weekly-routine)
[![Check](https://img.shields.io/badge/CHECK_before_use-site_is_JavaScript--only-orange?style=flat-square)](https://neetcode.io/roadmap)

> [!NOTE]
> **Roadmap assignment:** follow the roadmap order (arrays and hashing → two pointers → sliding window → stack → binary search → linked lists → trees → heaps → backtracking → graphs → dynamic programming), **about 3 problems a week**. **Skip:** paying for premium until the free problems are exhausted.
> **What you produce:** a **running count** in your lab notebook. Attempt each problem for **25 minutes** before watching the explanation.
>
> 📄 [Roadmap](https://neetcode.io/roadmap) · [Practice](https://neetcode.io/practice) · *checked 12 Oct 2026: the site loads but its lists render with JavaScript, so the exact problem lists couldn't be checked automatically. Open them in a browser.*

> [!TIP]
> **Why this is in an AI engineering plan:** North American ML and AI engineering interviews almost always include a coding round, and the skill decays fastest of anything you know. 3 hours a week keeps it alive while you go deep elsewhere.

## ⏱ The weekly routine (3 h)

| Block | What | Time |
| :--- | :--- | :-: |
| 1 | Problem 1: **25 min attempt**, no hints. Then the NeetCode video if stuck. Then re-code it from memory. | 55 min |
| 2 | Problem 2: same routine | 55 min |
| 3 | Problem 3: same routine | 55 min |
| 4 | Log it (below), plus one line on the *pattern* you learned | 15 min |

**Talk while you code** (out loud, or in comments). Silence reads as not knowing in an interview.
